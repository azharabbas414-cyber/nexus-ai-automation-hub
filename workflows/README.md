# n8n workflow

This folder is reserved for the importable n8n workflow export. The first cloud-ready milestone lets Streamlit call a webhook stored in the `N8N_WEBHOOK_URL` Streamlit secret. The n8n endpoint must be hosted separately; Streamlit Community Cloud does not host n8n itself.

In the next milestone we will provide a tested n8n workflow JSON and step-by-step import instructions. Keep the workflow in simulation mode and do not attach credentials for production systems.
